# 언제볼래 — 안 되는 날만 표시하는 약속 잡기 웹앱

친구들이 달력에서 **안 되는 날만 X** 치면, 표시하지 않은 날을 되는 날로 세어 **모두 되는 날**을 바로 보여 준다. 방장이 그중 하루를 확정한다.

지금은 **체험판**이다. 계정과 방이 이 브라우저(localStorage)에만 저장되므로, 친구가 자기 폰에서 링크를 열면 방이 보이지 않는다. 실제로 함께 쓰려면 서버 저장을 붙여야 한다 → [docs/handoff.md](docs/handoff.md)

## 실행

```bash
cd meetup_web
npm install
npm run dev            # http://localhost:3058
npm run check:tally    # 집계 규칙 검사
npm run build          # dist/ 에 빌드
```

같은 네트워크의 다른 기기에서 열려면 `npm run dev -- --host 0.0.0.0`으로 띄운다. 서버 바깥에서 열려면 방화벽(클라우드 콘솔의 보안 규칙 포함)에서 3058을 열어야 한다.

포트는 3058로 고정이다(`strictPort`). 같은 저장소의 다른 앱과 겹치지 않게 정했다.

| 앱 | 폴더 | 포트 |
|---|---|---|
| 아이디어 보드 | `/` (저장소 루트) | 3000 |
| 계약서 대조 | `New_project/` | 3055 |
| 모임 일정 잡기 | `meeting_app/` | 3057 |
| **언제볼래** | `meetup_web/` | **3058** |

기술: React 19, React Router 7, Vite 8. 서버와 DB는 없다.

## 기능

| 기능 | 내용 |
|---|---|
| 로그인 | 이름이 아이디(최대 10글자), 비밀번호는 정확히 4글자. 처음 보는 이름이면 한 번 물어보고 가입시킨다. 마지막으로 쓴 때부터 10분 안에 다시 열면 그대로 로그인돼 있다 |
| 처음 화면 | 내가 속한 방 목록(만든 방 + 참여한 방, 최근에 들어간 순), 방 만들기, 받은 링크 붙여넣기 |
| 방 만들기 | 방 이름(최대 10자) + 숫자 암호(최대 8자리). 만들면 「링크+암호」를 한 번에 복사할 수 있다 |
| 방 참여 | 처음 들어가는 방은 방 암호를 입력한다. 한 방에 최대 8명. 로그인 전에 방 링크를 열면 로그인한 뒤 그 방으로 돌아간다 |
| 안 되는 날 | 달력에서 탭하거나 드래그해서 X를 친다. 손을 떼면 바로 저장된다. 기간은 오늘부터 3개월 뒤 말일까지 |
| 결과 | 기간 고르기(전체 / 2주 / 4주 / 직접 입력), 참석 가능한 인원이 많은 순서의 날짜 순위, 달력 보기 |
| 날짜 상세 | 되는 사람 / 안 되는 사람, 날짜별 메모(최대 100자). 방장은 날짜 확정과 확정 취소 |
| 방 메뉴 | 링크 복사. 방장은 이름 변경·암호 변경·방 삭제, 참여자는 방 나가기 |
| 화면 모드 | 헤더 오른쪽 위 버튼으로 자동(기기 설정 따라감) → 라이트 → 다크. 고른 값은 이 브라우저에 기억한다 |
| 실시간 반영 | 같은 브라우저의 다른 탭에서 바꾼 내용이 바로 반영되고 알림이 뜬다 |

## 화면 흐름

```
/login     로그인 (로그인 전에는 어느 주소든 여기로 온다)
/          처음 화면: 내가 속한 방 목록, 방 만들기, 받은 링크 붙여넣기
/new       방 만들기 → 링크·암호 안내
/r/:id     방: (처음이면) 방 암호로 참여 → [내 안 되는 날 | 결과 보기]
```
