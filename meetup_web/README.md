# 언제볼래 — 불가능한 날만 표시하는 약속 잡기 웹앱

친구들이 달력에서 **불가능한 날만 X** 치면, 표시하지 않은 날을 가능한 날로 세어 **모두 가능한 날**을 바로 보여 준다.
모임은 한 번 만들면 계속 쓴다. 모임장이 **약속**(이름·카테고리)을 만들어 두고, 결과를 보고 날짜를 골라 확정한다. 약속이 하나씩 쌓이고 지난 약속도 다시 볼 수 있다.

저장 방식은 두 가지다.

- **서버 모드**: `VITE_SUPABASE_URL`·`VITE_SUPABASE_ANON_KEY`가 있으면 Supabase에 저장한다. 친구들이 각자 폰에서 같은 모임을 쓴다. 인터넷에 올리는 방법 → [docs/deploy.md](docs/deploy.md)
- **체험판**: 두 값이 없으면 이 브라우저(localStorage)에만 저장한다. 서버 없이 화면을 확인할 때 쓴다.

## 실행

```bash
cd meetup_web
npm install
npm run dev            # http://localhost:3059
npm run check:tally    # 집계 규칙 검사
npm run build          # dist/ 에 빌드

# 디자인 바꿔 보기: 스프링 벽걸이 달력 디자인 (기능·문구는 같다)
VITE_LOOK=mono npm run dev -- --port 3061
```

같은 네트워크의 다른 기기에서 열려면 `npm run dev -- --host 0.0.0.0`으로 띄운다. 서버 바깥에서 열려면 방화벽(클라우드 콘솔의 보안 규칙 포함)에서 3059를 열어야 한다.

포트는 3059로 고정이다(`strictPort`). 같은 저장소의 다른 앱과 겹치지 않게 정했다.

| 앱 | 폴더 | 포트 |
|---|---|---|
| 아이디어 보드 | `/` (저장소 루트) | 3000 |
| 계약서 대조 | `New_project/` | 3055 |
| 모임 일정 잡기 | `meeting_app/` | 3057 |
| **언제볼래** | `meetup_web/` | **3059** |

기술: React 19, React Router 7, Vite 8. 저장은 Supabase(서버 모드) 또는 이 브라우저의 localStorage(체험판).

## 기능

| 기능 | 내용 |
|---|---|
| 로그인 | 이름이 아이디(최대 10글자), 비밀번호는 정확히 4글자. 처음 보는 이름이면 한 번 물어보고 가입시킨다. 마지막으로 쓴 때부터 10분 안에 다시 열면 그대로 로그인돼 있다 |
| 처음 화면 | 빨간 머리띠 「○○님의 모임」 오른쪽 끝에 [+ 모임 만들기]. 내가 속한 모임 목록은 [최신순 \| 가나다순]으로 정렬(모임이 2개 이상일 때). 모임장은 [삭제], 모임원은 [나가기]. 속한 모임이 없으면 「아직 참여 중인 모임이 없어요✨」. 받은 링크 붙여넣기 칸 |
| 모임 만들기 | 모임 이름(최대 10자) + 숫자 암호(최대 8자리). 만들면 「링크+암호」를 한 번에 복사할 수 있다 |
| 모임 참여 | 처음 들어가는 모임은 모임 암호를 입력한다. 한 모임에 최대 8명. 로그인 전에 모임 링크를 열면 로그인한 뒤 그 모임으로 돌아간다 |
| 모임 설정 (✎) | 모임 이름 왼쪽 ✎ → 링크 복사. 모임장은 이름 변경·암호 변경·모임 삭제, 모임원은 모임 나가기 |
| 모임 안 내 이름 | 「○○님으로 참여 중」 옆 [이름 ✎]. 이 모임 안에서만 쓰는 이름(닉네임, 최대 10자)이고 계정 이름은 그대로. 같은 모임 안에서 겹치는 이름은 안 된다 |
| 불가능한 날 | 달력에서 탭하거나 드래그해서 X를 친다. 손을 떼면 바로 저장된다. 기간은 오늘부터 3개월 뒤 말일까지. X는 약속을 확정·취소해도 그대로 남는다 |
| 결과 | 기간 고르기(전체 / 2주 / 4주 / 직접 입력), 참석 가능한 인원이 많은 순서의 날짜 순위, 달력 |
| 날짜 상세 | 가능한 사람 / 불가능한 사람, 날짜별 메모(최대 100자). 모임장은 「이 날짜로 확정할 약속」을 골라 확정한다(날짜 미정 약속이 먼저, 이미 날짜가 있는 약속은 옮기기) |
| 약속 | 달력 위 약속 줄: [+ 새 약속](모임장), 다가오는 약속, 날짜 미정 약속, 오른쪽 끝 [지난 약속] 탭. 새 약속은 이름(최대 20자)과 카테고리만 정하고 날짜는 나중에. 같은 날짜에는 약속 하나 |
| 약속 창 | 약속을 누르면 가능한/불가능한 사람, [초대장 만들기], [공지 복사]. 모임장은 ✎ 이름·카테고리 수정, 날짜 확정 취소(날짜 미정으로 돌아감), 약속 삭제 |
| 초대장 | 약속의 카테고리(술자리·카페·생일파티·여행·운동·홈파티·걸스나잇)로 바로 시작한다(기타면 고른다). 그 종류의 배경·색·글꼴·문구·그림으로 9:16 세로 초대장을 만든다. 제목은 약속 이름. 이미지 복사·저장, 휴대폰에서는 공유하기 |
| 모임원 패널 | 모임 오른쪽. 날짜를 입력한 사람 옆에만 ✓, 안 한 사람은 비워 둔다. 모임장·나 표시 |
| 화면 모드 | 헤더 오른쪽 위 버튼으로 자동(기기 설정 따라감) → 라이트 → 다크. 고른 값은 이 브라우저에 기억한다 |
| 실시간 반영 | 다른 사람(다른 기기·다른 탭)이 바꾼 내용이 바로 반영되고 「방금 ○○님이 날짜를 바꿨어요」 알림이 뜬다 |

## 디자인 두 가지

| 디자인 | 켜는 법 | 모양 |
|---|---|---|
| 탁상 달력 (기본) | `npm run dev` | 크림색 종이, 빨간 머리띠와 링 구멍, 명조체 (`styles.css`) |
| 스프링 벽걸이 달력 | `VITE_LOOK=mono npm run dev` | 흰 종이 위 와이어 스프링(다크 모드는 흰 철사), 남색 격자 달력, 코발트 블록, 파스텔 스티커, Do Hyeon(제목·숫자) + Pretendard(본문) (`look-mono.css`) |

두 번째 디자인은 `<html data-look="mono">`일 때만 `look-mono.css`가 색·글꼴·모양을 덮어쓴다. 문구·기능은 같다. 배포 빌드에 쓰려면 빌드할 때 `VITE_LOOK=mono`를 준다.

## DB 업데이트 (2026-11-24)

약속과 모임 안 이름이 생기면서 DB가 바뀌었다. 서버 모드를 쓰고 있다면 Supabase SQL 편집기에서 [supabase/schema.sql](supabase/schema.sql)을 **한 번 다시 실행**한다(여러 번 실행해도 된다).

- 새 표 `appointments`(약속), 새 함수 `rename_member`(모임 안 이름 바꾸기)
- 예전 「확정 날짜」(`rooms.confirmed_date`)는 약속 하나로 옮겨진다(이름 = 모임 이름)
- 다시 실행하기 전에는 모임 화면은 열리지만 약속 만들기·확정과 이름 바꾸기가 실패한다

## 화면 흐름

```
/login     로그인 (로그인 전에는 어느 주소든 여기로 온다)
/          처음 화면: 내가 속한 모임 목록(정렬), [+ 모임 만들기], 받은 링크 붙여넣기
/new       모임 만들기 → 링크·암호 안내
/r/:id     모임: (처음이면) 모임 암호로 참여 → 약속 줄 → [불가능한 날 | 결과 보기]
```
