# PRD — 언제볼래

버전: v1.0 · 갱신일: 2026-10-31
이번에 바뀐 점: 지금까지 만든 체험판을 기준으로 처음 정리했다.

이 문서는 항상 현재 정답만 남긴다. 내용이 바뀌면 지우고 덮어쓴다.
사용자 인터뷰는 아직 하지 않았다. 아래 Q1·Q2·Q6은 만든 사람의 가정이고, 확인이 필요한 것은 「미확인」으로 표시했다.

## Q1. 누가 쓸까?

친구·동기 모임에서 약속 날짜를 잡는 일을 떠맡은 한 사람(총무 역할).
4~8명이 모이는 송년회나 정기 모임 날짜를 정하려고, 단톡방에 「언제 돼?」를 묻고 답을 모아 정리하는 사람이다.

(실제로 몇 명 규모의 모임이 가장 많은지, 몇 달 앞까지 잡는지는 미확인)

## Q2. 뭐가 답답한가?

1. 단톡방에 「되는 날 말해 줘」라고 올리면 답이 대화 사이에 흩어지고, 누가 답했는지 다시 확인해야 한다.
2. 「되는 날」을 다 적어 달라고 하면 적을 날이 많아 귀찮아서 답이 늦거나 오지 않는다. 사람들은 대개 「이날은 안 돼」가 더 빨리 떠오른다.
3. 모인 답을 손으로 세어 「모두 되는 날」을 찾다가, 누가 일정을 바꾸면 처음부터 다시 센다.

## Q3. 어떻게 풀까?

「모임 날짜를 잡는 총무를 위해, 친구들이 안 되는 날만 X 치면 모두 되는 날을 순위로 바로 보여 주는 도구예요.」

## Q4. 기능 딱 3개

1. **안 되는 날 표시**: 달력에서 탭하거나 드래그해서 안 되는 날에 X를 친다. 손을 떼면 바로 저장된다.
2. **되는 날 집계와 순위**: 표시하지 않은 날은 되는 날로 센다. 고른 기간 안에서 참석 가능한 인원이 많은 순으로 날짜 순위를 보여 주고, 날짜마다 안 되는 사람을 보여 준다. 집계는 규칙으로 처리하고 AI를 쓰지 않는다.
3. **방장 확정과 공유**: 방장이 날짜를 확정하면 방 맨 위에 확정 날짜가 나오고, 공지 문구를 복사할 수 있다.

이 셋을 받쳐 주는 것: 이름 + 4글자 비밀번호 로그인, 링크 + 숫자 암호로 방 참여, 날짜별 메모, 화면 모드(자동/라이트/다크).

안 할 것 (지금 범위 밖)
- 간편 로그인(Google·Apple), 즐겨찾기, 여러 방에 내 날짜 한 번에 적용, 색 테마, 결제, 네이티브 앱
- 시간대(몇 시) 단위 일정 조율. 날짜 하루가 최소 단위다.

## Q5. 어떻게 생겼나?

- **로그인**: 이름과 4글자 비밀번호. 처음 보는 이름이면 가입할지 한 번 묻는다.
- **처음 화면**: 내가 속한 방 목록(방장 표시, 인원 수, 확정 여부), [방 만들기], 받은 링크 붙여넣기 칸.
- **방 화면**: 탭 두 개.
  - [내 안 되는 날]: 한 달씩 넘기는 달력에 X를 친다. 「저장됨 ✓ 시각」이 보인다.
  - [결과 보기]: 기간 칩(전체 / 앞으로 2주 / 앞으로 4주)과 날짜 직접 입력 → 날짜 순위 카드 → 달력 보기(모두 되는 날은 꽉 채우고, 적게 될수록 흐리게).
  - 날짜를 누르면 아래에서 올라오는 창에 되는 사람 / 안 되는 사람, 메모, (방장) [이 날로 확정]이 나온다.
- 모든 화면 위쪽 헤더 오른쪽에 화면 모드 버튼이 있다.

## Q6. 성공의 모습

(제안, 미확인) 4명 이상이 모인 실제 모임 하나에서, 총무가 링크를 보낸 뒤 모든 사람이 각자 X 표시를 마치고, 총무가 단톡방에서 따로 다시 묻지 않고 결과 순위만 보고 날짜를 확정하면 성공.

지금은 체험판이라 이 기준을 확인할 수 없다. 서버 저장을 붙인 뒤 측정한다.

## 데이터·제약

- 쓸 수 있는 자료: 없음. 사용자가 직접 입력하는 이름·날짜·메모만 다룬다.
- 저장: 지금은 이 브라우저의 localStorage에만 저장한다. 여러 기기에서 함께 쓰려면 서버 DB가 필요하다(추천: Supabase).
- 보안: 계정 비밀번호와 방 암호를 그대로 저장한다. 서버로 옮길 때 해시로 바꾸고 확인도 서버에서 한다. 4글자 비밀번호는 쉽게 맞힐 수 있어 로그인 시도 횟수 제한이 필요하다.
- 비용: 서버를 붙이기 전까지는 없다.

## 한 단락 PRD

친구·동기 모임에서 날짜를 잡는 총무는 단톡방에서 되는 날을 묻고 흩어진 답을 손으로 세는데, 되는 날을 다 적어 달라고 하면 답이 늦고 누가 일정을 바꾸면 처음부터 다시 센다. 이 총무를 위해, 친구들이 안 되는 날만 X 치면 모두 되는 날을 순위로 바로 보여 주는 웹앱을 만든다. 반드시 만들 기능은 세 가지다. (1) 달력에서 탭하거나 드래그해서 안 되는 날을 표시하고 손을 떼면 바로 저장한다. (2) 표시하지 않은 날은 되는 날로 세어, 고른 기간 안에서 참석 가능한 인원이 많은 순으로 날짜 순위를 보여 준다. 집계는 AI가 아닌 규칙으로 처리한다. (3) 방장이 날짜를 확정하고 공지 문구를 복사한다. 사용자는 이름과 4글자 비밀번호로 로그인하고, 링크와 숫자 암호로 최대 8명이 한 방에 참여한다. 간편 로그인·결제·네이티브 앱·시간 단위 조율은 하지 않는다. 지금은 브라우저 저장소만 쓰는 체험판이고, 실제 모임에서 쓰려면 서버 저장과 비밀번호 해시를 붙여야 한다. 실제 모임 하나에서 모두가 표시를 마치고 총무가 따로 묻지 않고 결과만 보고 날짜를 확정하면 성공이다.
